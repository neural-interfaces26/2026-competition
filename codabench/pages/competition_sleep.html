Neural Interfaces 2026 · Track 03 · Cross-device shift

Sleep onset

Predicts the latency in seconds from recording start to the first stable N2 epoch, on consumer-grade wearable EEG.

The controlled shift is cross-device: home-wearable channels and montages instead of the clinical polysomnography setups of the seed corpora. Precise timing replaces full staging because the wearable signal is too sparse to support per-epoch hypnogram reconstruction.

The task

Your model receives torch batches X: (B, C, T) and must return one predicted latency per window, predict(X) -> (B,) floats, in seconds. Targets are capped at 600 s.

Ranking uses binned MAE: the MAE is computed inside time-to-onset bins of [0, 40, 90, 300, 600] s and averaged with equal weight across bins, so early-onset windows — rare, and the clinically interesting ones — count as much as the common late ones.

The public proxy dataset is Sleep-EDF (Kemp2000Analysis) through the neuralbench eeg/sleep_onset task config: non-overlapping 5-s windows over the pre-N2 part of each night, subject-level train/val/test split, and a bin sampler balancing train batches across latency bins. A zero-dependency Simulated dataset ships for no-network smoke tests.
